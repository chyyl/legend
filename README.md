# LEGEND — 像素大陆冒险

类《我的世界地下城2》的 **2D 像素风 · 火柴人** 动作 RPG。
纯 HTML5 + 原生 JavaScript（零构建、零依赖），可直接部署 GitHub Pages、可离线运行、可打包成 APK。

## 一、快速开始

```bash
# 方式 1：直接双击 index.html（单机完全可用）
# 方式 2：本地服务器（推荐，联机与 Service Worker 需要 http 环境）
python -m http.server 8080
# 打开 http://127.0.0.1:8080
```

### 操作
| 按键 | 功能 |
|---|---|
| `W A S D` / 方向键 | 移动 |
| 鼠标移动 | 瞄准 |
| 鼠标左键 | 攻击（按住连发） |
| `空格` | 翻滚闪避（无敌帧） |
| `E` / `F` | 交互（开宝箱 / NPC / 传送点） |
| `Q` | 使用药水 |
| `I` / `B` | 背包 |
| `M` | 大地图（可点击传送点传送） |
| `Esc` | 关闭面板 |
| 触屏 | 左半屏摇杆移动（带可视化）· 右半屏点按攻击 · 右下角按钮：交互/翻滚/药水 · 左下角菜单 |

> 手机/平板自动适配：渲染清晰度按设备 DPR 计算（1 游戏像素 = 2 物理像素），
> 视野自动缩放为约 10 格宽，横屏内容超高时可滚动，触控目标不小于 44px。

## 二、游戏特色（对应《游戏要求.txt》）

### 1. 大陆地图（2000×2000 格，程序化生成）
11 个区域按方位分布在同一块大陆上，探索后才在地图上显示：

| 区域 | 方位 | 区域 | 方位 |
|---|---|---|---|
| 营地（首发需解放，有NPC） | 东南 | 西北兵工厂 | 西北 |
| 边境长城 | 东南-东 | 绝壁雪山 | 中西-西 |
| 海湾小镇 | 东 | 跨海大桥 | 西 |
| 彬祥农业园 | 东北 | 骷髅岛 | 中 |
| 黑暗迷宫 | 东北-北 | 黑暗城堡 | 西南 |
| 终末之战 | | 南 |

- **地形**：分形噪声高度图 + 区域主题，自动处理 **地面 / 水 / 山体**（水域与高山阻挡移动，区域之间自动铺路并**架桥跨水**，保证全图连通）。
- **传送点**：每个区域一个，探索后解锁，大地图点击即可传送。
- **宝箱**：全图散落，未开的会呼吸发光，可开出高品质装备。

### 2. 品质与掉落（概率严格按要求表）
| 武器品质 | 概率 | 属性 |
|---|---|---|
| N 普通 | 80% | 无 |
| R 稀有 | 15% | 伤害+30%，羁绊 1-2 个 |
| SR 史诗 | 3.5% | 伤害+50%，攻速+10%~30%，范围+20%，羁绊 2-3 个 |
| SSR 传说 | 1.5% | 伤害+65%，攻速+20%~50%，范围+20%~35%，羁绊 2-4 个 |

| 装备品质 | 概率 | 属性 |
|---|---|---|
| D | 50% | 无 |
| C | 25% | 防御+10%~20% |
| B | 15% | 防御+20%~30%，移速+10%~20%，羁绊 1 个 |
| A | 6% | 防御+20%~35%，移速+10%~25%，伤害+10%~25%，羁绊 1-2 个 |
| S | 3% | 防御+30%~40%，移速+10%~30%，伤害+20%~30%，闪避+20%~30%，羁绊 2-3 个 |
| SS | 1% | 防御+35%~50%，移速+10%~40%，伤害+30%~55%，闪避+25%~40%，羁绊 2-4 个 |

武器与装备均有 **1-10 级**，通过使用与任务成长。

### 3. 8 种羁绊（天生自带，类似附魔）
锋利（伤害+30%）· 横扫之刃（范围+40%）· 经验获取（经验+50%）· 力量（伤害+15%、攻速+15%）·
三倍暴击（3倍暴击率+8%）· 保护（防御+30%）· 吸血（5%吸血）· **不死金牌**（致命伤触发无敌5秒，冷却60秒）

### 4. 敌人与难度
- **普通**：生命 = 难度系数 × 基础生命
- **精英怪**：生命 ×250%~400%，伤害 (+10%~30%)×难度系数
- **BOSS**：生命 ×500%~1000%，伤害 (+15%~40%)×难度系数
- 敌人武器属性 = 玩家的 30%
- **难度系数 0-2**（默认 0.9，可调），同时影响敌人强度、数量与掉落品质

### 5. 经济系统
击杀奖励 = **敌人等级 × 10 × r × 难度系数**，其中 `r`：普通 30%、精英 200%、BOSS 400%。
完成任务额外奖励银币、经验，并**有概率获得武器装备**。

### 6. 其他
- 火柴人像素渲染（低分辨率绘制 + `image-rendering: pixelated` 放大）
- 任务系统（10 个任务带前置链：解放营地 → 各区域 → 终末之战）
- 探索迷雾：未探索区域在地图上隐藏
- 区域解放：击杀进度满或击败区域 BOSS 即解放，营地解放后 NPC 出现
- 自动存档（20 秒）+ 手动存档

## 三、多人联机（1-4 人，可一个人玩）

开始界面 → **联机大厅**：
1. 房主点击「创建房间」，获得 **6 位房间码**
2. 队友输入房间码点「加入房间」
3. 最多 4 人，同步移动/攻击/敌人快照；单人点「单人开始」即可

技术：**WebRTC (PeerJS)**，使用免费公共信令服务器，**零服务器成本**。
离线或 PeerJS 加载失败时自动降级为纯单机，不影响单机体验。

## 四、部署 GitHub Pages（零成本）

### 方式 A：直接上传（最快）
1. 新建 GitHub 仓库，上传本项目全部文件
2. 仓库 **Settings → Pages → Source** 选择 `Deploy from a branch`
3. Branch 选择 `main` / `(root)`，保存
4. 访问 `https://<用户名>.github.io/<仓库名>/`

### 方式 B：GitHub Actions 自动部署（推荐）
项目已内置 `.github/workflows/deploy.yml`，推送到 `main` 分支即自动发布：

```bash
git init
git add .
git commit -m "LEGEND v1"
git branch -M main
git remote add origin https://github.com/<用户名>/<仓库名>.git
git push -u origin main
```

## 五、打包 APK 离线版（最低成本）

游戏已内置 **PWA 支持**（`manifest.json` + `sw.js` 离线缓存），因此有两种打包路径：

### 路径 1：WebView 壳（5 分钟，推荐）
```bash
npm init -y
npm i @capacitor/core @capacitor/cli @capacitor/android
npx cap init "LEGEND" "com.legend.game" --web-dir=www
mkdir www && cp -r index.html css js assets manifest.json sw.js www/
npx cap add android
npx cap sync
npx cap open android      # 在 Android Studio 里 Build APK
```

### 路径 2：在线转换（无需安装 Android Studio）
1. 先按上面部署到 GitHub Pages
2. 打开 [pwabuilder.com](https://www.pwabuilder.com)，输入你的 Pages 地址
3. 选择 **Android → Generate**，下载 `.apk` / `.aab`

> 两种方式都不需要改任何游戏代码；`sw.js` 已缓存全部资源，APK 首次联网加载后**完全离线可玩**。

## 六、项目结构与接口

每个文件头部都有注释，写明「职责 / 依赖 / 对外接口 / 被引用」，文件间**只通过接口访问**，改一个文件不影响其他文件。

```
legend/
├── index.html              入口（含脚本加载顺序注释）
├── manifest.json           PWA 清单（APK/安装基础）
├── sw.js                   Service Worker（离线缓存）
├── css/style.css           像素风样式
├── js/
│   ├── data/config.js      数值中心（区域/品质/羁绊/武器/敌人/难度）
│   ├── core/utils.js       随机/数学/事件总线/存储
│   ├── core/input.js       键鼠 + 触屏输入
│   ├── world/terrain.js    程序化地形（噪声 + 水/山/桥处理）
│   ├── world/worldmap.js   大世界状态（探索/传送点/宝箱/解放）
│   ├── world/renderer.js   像素火柴人渲染
│   ├── systems/loot.js     掉落与品质/羁绊生成
│   ├── systems/combat.js   战斗数值结算
│   ├── systems/quest.js    任务系统
│   ├── systems/save.js     存档
│   ├── entity/player.js    玩家
│   ├── entity/enemy.js     敌人 AI（普通/精英/BOSS）
│   ├── entity/npc.js       NPC
│   ├── entity/projectile.js远程弹道
│   ├── net/multiplayer.js  联机
│   ├── ui/ui.js            全部界面
│   └── game.js             主循环与整合
└── docs/API.md             完整接口文档（模块间契约）
```

**详细接口见 [docs/API.md](docs/API.md)**

## 八、技术要点

- **零构建**：原生 JS + 全局 `Legend` 命名空间，script 按依赖顺序加载，任何静态服务器可跑
- **像素风**：Canvas 以 1/2 分辨率绘制后 CSS 放大，配合 `image-rendering: pixelated`
- **性能**：地形按需计算 + 6 万格 LRU 缓存，只渲染视口内格子，小地图 96×96 预生成
- **解耦**：模块间仅通过 `docs/API.md` 约定的接口 + 事件总线通信
