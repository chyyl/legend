## 4. 页面清单

数组顺序须符合用户的真实决策顺序，不按后台菜单顺序排。每页主要操作恰好一个。

### 4.1 <页面名>

| 字段 | 内容 |
|---|---|
| name | 示例：跟进质量看板 |
| goal | 示例：判断本周客户跟进是否达标 |
| reason | 示例：运营专员每日首次进入系统即需判断整体状况，无此页需逐条翻查列表 |
| entry | 示例：登录后默认落地 |
| exit | 示例：成功 → 客户明细列表；失败 → 停留在本页并显示错误条 |
| permission | 示例：运营专员与店长可见 |

区块列表，顺序须符合用户在该页的决策顺序。priority 1 为最高。

| 区块 | 用途 | 优先级 | 字段 |
|---|---|---|---|
| 示例：超期指标卡 | 概览超期客户数量与占比 | 1 | 示例：超期数、占比 |
| 示例：趋势图 | 判断超期趋势方向 | 2 | 示例：近 7 日超期数 |
|  |  |  |  |

| 操作 | 类型 | 结果 | 作用目标 |
|---|---|---|---|
| 示例：查看超期客户 | 主要 | 示例：跳转客户明细列表并带入筛选条件 | 示例：超期指标卡 |
| 示例：切换时间范围 | 次要 | 示例：刷新指标卡与趋势图 | 示例：时间选择器 |

状态覆盖，必须含主态、空态、错态、加载态、权限态五项。

| 状态 | 表现 |
|---|---|
| 主态 | 示例：显示指标卡与趋势图 |
| 空态 | 示例：说明需要接入客户与跟进数据源，并给接入入口 |
| 错态 | 示例：区分数据源失败与筛选过窄，保留筛选条件并提供重试 |
| 加载态 | 示例：指标卡与图表区各自骨架，形状贴近真实内容 |
| 权限态 | 示例：说明缺少看板查看权限并给申请入口 |

跳转目标须存在于 pages 中：示例：客户明细列表。
