## 2. 状态机

每个交互流程一张表。状态迁移须闭合，不允许无出口状态。

### 2.1 示例：加载看板数据

| 当前状态 | 事件 | 下一状态 | 副作用 | 可否用户干预 |
|---|---|---|---|---|
| idle | 示例：进入页面 | loading | 示例：请求指标接口 | 否 |
| loading | 示例：接口成功 | success | 示例：渲染指标卡与图表 | 否 |
| loading | 示例：接口失败 | error | 示例：显示错误条 | 示例：可点重试 |

## 5. 响应式实现要点

见 `data/responsive-breakpoints.json`。

| 断点 | 实现要点 |
|---|---|
| sm | 示例：指标卡 grid 单列，表格改卡片式行布局，主要操作固定底部 |
| md | 示例：指标卡 3 列，表单 label 与输入框同行 |
| lg | 示例：侧边导航固定展开，表格全列显示 |
| xl | 示例：容器最大 1200px 居中，不加列 |

移动端触控目标不小于 44x44px。任何断点不得出现横向滚动条，表格可用内部滚动容器并设 tabindex 为 0。
