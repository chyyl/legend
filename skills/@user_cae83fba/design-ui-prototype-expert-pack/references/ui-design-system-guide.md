# UI 与设计系统指南

## 0. 参数化最小规范（必须给出）

UI 规格必须包含“可执行参数”，不能只写风格形容词。建议最少覆盖：
- 字体层级（至少标题/区块标题/正文/辅助说明）。
- 间距 token（至少 4/8/12/16/24/32）。
- 颜色语义（主色/成功/警示/错误/中性色）。
- 响应式断点（至少移动端、笔记本、桌面宽屏）。
- 触控尺寸（移动端可点击区域建议 >= 44x44）。

## 1. UI 规格不是形容词清单

不要只写“高级、现代、简洁”。需要明确：
- 字体层级。
- 颜色语义。
- 间距规则。
- 组件样式。
- 状态反馈。
- 可读性要求。

## 2. 字体层级

建议至少定义：
- 页面标题。
- 区块标题。
- 正文。
- 辅助说明。
- 表格内容。
- 错误提示。

每一层都要说明使用场景，而不是只给字号。

推荐默认值（可按品牌调整）：
- 页面标题：24px / 700 / 行高 1.3。
- 区块标题：16px / 600 / 行高 1.4。
- 正文：14px / 400-500 / 行高 1.5。
- 辅助说明：12px / 400 / 行高 1.5。
- 错误提示：12-14px / 500 / 行高 1.4。

可读性红线：
- 关键信息不使用小于 12px 文本。
- 主要阅读文本建议不低于 14px（后台高密场景可例外，但必须验证可读性）。
- 缩略图或压缩预览下，标题、关键指标、主按钮、错误信息必须仍可识别。

## 3. 颜色规则

颜色应服务任务：
- 主色：关键操作和当前状态。
- 成功色：完成、保存、通过。
- 警示色：风险、临期、需要关注。
- 错误色：失败、阻断、不可继续。
- 中性色：文本、边框、背景、分割。

对比度门槛（建议作为验收下限）：
- 普通文本：>= 4.5:1。
- 大号文本：>= 3:1。
- 图标与关键控件：>= 3:1。

不要只靠颜色表达状态；应同时配合图标、文案或形状差异。

## 3.1 间距与密度基线

推荐 token（可映射到项目命名）：
- spacing-4: 4px
- spacing-8: 8px
- spacing-12: 12px
- spacing-16: 16px
- spacing-24: 24px
- spacing-32: 32px

密度建议：
- 信息密集页面（后台/表格）：行内间距 8-12，区块间距 16-24。
- 常规页面：行内间距 12-16，区块间距 24-32。
- 不允许在同一页面混入大量随机间距值。

## 3.2 对比度计算方法

对比度须可复算，不能只给结论。计算五步：

| 步骤 | 动作 | 说明 |
|---|---|---|
| 1 | 取前景色与背景色的 sRGB 相对亮度 L | 前景为文字色，背景为该文字实际所处底色（含父级底色叠加后的结果色） |
| 2 | 按 `(L1 + 0.05) / (L2 + 0.05)` 计算比值 | L1 取较亮者，保证结果大于等于 1 |
| 3 | 判定普通文本 | 低于 4.5:1 判不通过 |
| 4 | 判定大号文本 | 大号为不小于 24px，或不小于 18.66px 的粗体；判 3:1 |
| 5 | 判定图标与关键控件 | 边界、输入框、图标、图表关键标记判 3:1 |

相对亮度 L 的计算：先把 sRGB 各通道值归一化到 0 至 1，低于 0.03928 的取 `c / 12.92`，其余取 `((c + 0.055) / 1.055)` 的 2.4 次方，再按 `0.2126 R + 0.7152 G + 0.0722 B` 加权。

语义色不因语义而豁免：成功色、警示色、错误色作为文字使用时，同样按 4.5:1 判定；作为色块使用时，前景文字与该色块之间仍需达标。

记录格式：

| 元素 | 前景色 | 背景色 | 前景 L | 背景 L | 比值 | 门槛 | 结论 |
|---|---|---|---|---|---|---|---|
| 正文 | #1d1d1f | #ffffff | 0.0 | 1.0 | 18.4:1 | 4.5:1 | 通过 |
| 辅助说明 | #7a7a7a | #ffffff | 0.0 | 1.0 | 4.2:1 | 4.5:1 | 不通过，需加深至 #6b6b6b |

## 4. 组件状态

核心组件至少包含：
- 默认态。
- 悬停态。
- 聚焦态。
- 禁用态。
- 加载态。
- 成功态。
- 错误态。

建议补齐：
- 激活态（Active/Pressed）。
- 选中态（Selected，适用于标签、列表项、分段控件）。

状态最小矩阵（交付时必须能对照，8 类组件）：

| 组件 | 必须覆盖的状态 |
|---|---|
| Button | 默认 / 悬停 / 激活 / 聚焦 / 禁用 / 加载 |
| Input | 默认 / 聚焦 / 校验中 / 错误 / 成功 / 禁用 |
| Table 行 | 默认 / 悬停 / 选中 / 禁用 |
| Modal | 打开 / 关闭 / 加载 / 提交成功 / 提交失败 |
| Tab | 默认 / 激活 / 悬停 / 禁用 / 聚焦 |
| Switch | 关 / 开 / 悬停 / 聚焦 / 禁用 / 加载 |
| Breadcrumb | 默认 / 悬停 / 当前项 / 折叠溢出 |
| Pagination | 默认 / 悬停 / 激活 / 禁用 / 聚焦 / 边界（首页、末页） |

## 4.1 交互动效基线（新增）

建议统一时序，避免每个页面风格不一致：
- 点击反馈：80-150ms。
- 轻量切换（hover/active）：120-200ms。
- 弹层/抽屉开合：180-300ms。
- 页面区块切换：200-350ms。

动效原则：
- 先反馈，再装饰；反馈优先于视觉花哨。
- 错误反馈必须快于成功反馈，避免用户误判。
- 对于动态偏好降低场景，保留功能反馈，弱化非必要动画。

## 5. 设计系统输出

推荐输出：
- 语义 token 表。
- 组件清单。
- 组件状态表。
- 使用边界。
- 与前端实现相关的注意事项。

token 分层建议（便于工程落地）：
- 原始值层（Primitive）：颜色原始值、基础字号、基础间距。
- 语义层（Semantic）：primary-text、danger-bg、spacing-content-gap。
- 组件层（Component）：button-primary-bg、table-row-hover-bg。

同一个输出里应说明：
- 哪些 token 可跨页面复用。
- 哪些只适用于当前页面（一次性规则，避免误复用）。
- 与前端映射建议（CSS 变量、Tailwind token 或组件 props）。

## 6. 可读性要求

在缩略图或预览状态下，标题、关键指标、按钮和错误提示必须可读。不要用过小的装饰文字承担关键信息。

## 7. 响应式规则最小集

建议至少定义这四档：
- 移动端：< 768。
- 笔记本：768-1279。
- 桌面宽屏：1280-1919。
- 大屏：>= 1920，内容区限宽居中（表格与长文本场景建议限宽 1200 至 1440，两侧留白），不整体拉伸。

每一档都应说明：
- 页面是否改列数（如 1 列 -> 2 列 -> 3 列）。
- 主要表格如何处理（横向滚动、字段折叠、卡片化）。
- 主操作按钮位置是否变化。

## 8. 高级约束（P2 补强）

### 国际化与多语言
- 文案可能膨胀 30%-40%，按钮和表格列应预留空间。
- 避免用固定宽度承载关键文案。
- 需要 RTL 的项目应优先使用逻辑方向属性（如 inline-start/end）。

### 性能友好设计
- 首屏尽量控制大图数量，关键图建议有压缩策略。
- 字体家族建议不超过 2 套，避免首屏加载负担过大。
- 长列表优先分页或虚拟化方案，避免一次渲染过重。
- 动效优先使用 transform/opacity，减少布局抖动。

## 9. 可选交叉验证：启发式评分

当用户明确要求可用性评估，或 06 段结论为「带风险通过」时，可引入 Nielsen 10 条启发式评分作为交叉验证维度。

| 项 | 规则 |
|---|---|
| 定位 | 可选维度，不替代 7 维 100 分制 |
| 参与判定 | 不参与通过与带风险通过的结论判定 |
| 呈现方式 | 与 100 分制评分并行呈现，不合并不换算 |
| 详细规则 | 见 `references/design-heuristics.md` |

## 10. 无障碍判定细则

七项判定，逐项给判定方式与不通过后果（对应红线 R6）。

| 编号 | 项 | 判定标准 | 不通过后果 |
|---|---|---|---|
| A1 | 对比度 | 正文不低于 4.5:1；大号文本（不小于 24px 或不小于 18.66px 粗体）、图标与关键控件不低于 3:1；计算可复算 | 弱视用户读不到内容（复算见第 3.2 节） |
| A2 | 焦点可见 | 键盘操作时焦点有可见指示；移除默认 outline 时已提供等效替代；焦点环对比度不低于 3:1 | 键盘用户无法判断当前焦点位置 |
| A3 | 键盘可达 | 主路径全部可由 Tab 到达并触发；无鼠标专属交互；焦点顺序与视觉顺序一致 | 键盘用户部分功能不可达 |
| A4 | 状态冗余 | 状态不只靠颜色传达，颜色、图标、文字三者至少提供两个 | 色觉障碍用户误判状态 |
| A5 | 动效降级 | 支持 `prefers-reduced-motion`；动画可中断；终态与焦点状态正确 | 部分用户出现不适或状态错乱 |
| A6 | 语义化属性 | 使用正确标签；图标按钮补 `aria-label`；表单控件关联 `label`；状态变更用 `aria-expanded` / `aria-live` | 读屏软件读不出结构与状态 |
| A7 | 触控尺寸 | 可点击区域不小于 44x44 | 触屏用户误触或点不中 |

七项中 A1、A2、A3、A4 为主要门槛，任一不达标即判不通过。A5 至 A7 不达标时标风险并给出修正动作。
