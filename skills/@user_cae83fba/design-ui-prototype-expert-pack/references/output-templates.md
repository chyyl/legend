## UI 参数建议表（新增）

| 项目 | 建议值 | 可调整范围 | 风险提示 |
|---|---|---|---|
| 页面标题字号 | 24px | 20-32px | 过小会削弱层级 |
| 正文字号 | 14px | 14-16px | 小于 14px 需说明场景 |
| 行高 | 1.4-1.6 | 1.3-1.75 | 过小影响可读性 |
| 常用间距 | 8/12/16/24 | 按 token 扩展 | 随机间距会破坏一致性 |
| 主交互时长 | 100-300ms | 80-400ms | 过慢影响反馈速度 |
| 触控最小尺寸 | 44x44 | 44-48 | 过小影响可点击性 |
| 主色对比度 | >= 3:1 | 更高更稳妥 | 低对比度可达性差 |
| 正文对比度 | >= 4.5:1 | 更高更稳妥 | 无法通过无障碍验收 |
