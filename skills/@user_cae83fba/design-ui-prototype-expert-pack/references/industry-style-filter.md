# 03 段行业反模式过滤

本文件供 `experts/03-wireframe-to-ui-expert.md` 使用。输入行业类别，输出禁忌约束与风格方向建议，写入 UI 规格的 AVOID 栏。

## 1. 使用方式

| 步骤 | 动作 | 输出 |
|---|---|---|
| 1 | 判定行业类别（可多选） | 行业标签 |
| 2 | 查禁忌矩阵，得到 4 个维度的禁忌项 | 禁忌清单 |
| 3 | 从风格方向表中选 1 个主方向 + 1 个辅方向 | 风格方向 |
| 4 | 把禁忌项写入 UI 规格 AVOID 栏 | 可判定条目 |

## 2. 行业 × 禁忌维度矩阵

| 行业类别 | 风格优先级禁忌 | 色彩禁忌 | 动效禁忌 | 布局禁忌 |
|---|---|---|---|---|
| 金融银行保险 | 拟物化、厚阴影、装饰纹理 | 大面积红绿对撞、荧光饱和色、渐变紫粉 | 弹跳入场、循环呼吸动效 | 倾斜透视布局、非网格对齐 |
| 医疗健康 | 花哨渐变、拟物化 | 纯饱和红（易与危急值混淆）、亮黄 | 快速闪烁、持续脉冲动效 | 圆角过度、装饰插画抢占信息位 |
| 企业级 SaaS | 拟物化、玻璃拟态正文承载 | 紫粉渐变、暗黑模式底色 | 视差滚动、装饰性循环动效 | 卡片堆叠无主次、居中大留白配窄内容 |
| 政务公共服务 | 玻璃拟态、暗黑模式、高饱和大面积色块 | 低对比度浅灰配白底、纯灰无层次 | 动画超过 300ms、并行动效互相干扰 | 依赖 hover 才显示的关键信息、多层折叠 |
| 电商消费品 | 极简无商品信息层级 | 灰底低对比、纯白底配浅灰字 | 无限轮播、强制自动播放 | 首屏无价格与主操作、商品卡无主次 |

## 3. 风格方向表

| 组 | 方向 | 适用 | 性能代价 | 无障碍注意 |
|---|---|---|---|---|
| 极简系 | Minimalism | 政务、企业后台、内容型产品 | 低 | 需靠对比与间距建立层级，弱化装饰时更依赖对齐 |
| 极简系 | Swiss / International Typographic | 金融、数据密集、报表类 | 低 | 网格严格，窄屏需重排 |
| 极简系 | Brutalism | 创意工具、活动页、开发者产品 | 低 | 反差强烈，正文长文可读性下降 |
| 极简系 | Flat 2.0 | 通用后台与列表页 | 低 | 缺阴影时需靠边框与底色区分可点击区 |
| 现代系 | Material | 通用 C 端、Android 为主 | 中 | 阴影层数多，需控制叠加层数 |
| 现代系 | Soft UI Evolution | 工具类、后台配置页 | 中 | 内外阴影叠加增加重绘开销 |
| 现代系 | 拟物系 | 品牌营销页、硬件配套 | 中至高 | 拟物阴影降低文字对比度，正文承载需另配纯色底 |
| 现代系 | Neumorphism | 音乐类、冥想类、装饰性区块 | 中 | 不建议用于正文承载：同色系浅浮雕使文字与背景对比度极低，通常低于 4.5:1 |
| 玻璃系 | Glassmorphism | 品牌展示、背景图叠加层 | 中至高 | 不建议用于正文承载：毛玻璃降低文字对比度，正文需落在不透明底色上；实时模糊有性能开销 |
| 玻璃系 | 暗色系 | 影音、开发者工具、夜间场景 | 低 | 暗底纯灰文字易低于 4.5:1；需避免纯黑底配纯白字造成眩光 |
| 品牌型 | 品牌驱动 | 有既有 VI 的产品 | 视素材而定 | 品牌色需逐个校验对比度，达标后才用于文本 |
| 品牌型 | 极繁主义 | 活动页、发布页、限定主题 | 中至高 | 装饰层多，需保证主操作与正文在视觉层级上优先 |

## 4. 方向选择规则

| 场景 | 建议方向 |
|---|---|
| 数据密集后台 | Swiss 或 Flat 2.0 |
| C 端移动应用 | Material 或 Minimalism |
| 品牌营销页 | 品牌驱动 + 极繁主义（仅活动页） |
| 财务报表与合规页 | Swiss + 高对比中性色 |
| 开发者工具 | 暗色系或 Brutalism |

## 5. AVOID 栏输出规范

UI 规格的 AVOID 栏按下列格式输出，每条必须可判定（能说出「怎么观察到违规」）。

| 字段 | 要求 |
|---|---|
| 禁忌项 | 引用矩阵中的维度与条目原文 |
| 判定方式 | 说明如何观察到违规，例如「正文与背景对比度低于 4.5:1」 |
| 替代方案 | 给出可用方向，引用风格方向表 |
| 适用范围 | 说明该禁忌在哪些页面生效 |

格式示例：

```
AVOID：
- 拟物化厚阴影（判定：卡片阴影扩散值大于 8px 且带内阴影；替代：Flat 2.0 细边框；范围：全部列表页）
- 紫粉渐变（判定：主色为紫粉渐变且用于后台页面；替代：单色主色 + 语义色；范围：全部后台页面）
- 循环呼吸动效（判定：存在 infinite 循环动画承载信息；替代：静态状态徽章；范围：首页与列表页）
```

## 6. 跨行业通用禁忌

以下 5 项在所有行业类别下均成立，不受矩阵限制。

| 禁忌项 | 判定方式 | 替代方案 |
|---|---|---|
| emoji 当图标 | 图标位置出现 emoji 字符 | 统一图标集的 SVG 图标 |
| 混用图标风格 | 同一界面出现 2 套以上描边风格 | 单一图标集，统一线宽 |
| 装饰动效阻碍操作 | 动效期间无法点击或滚动被锁 | 动效只作用于 transform 与 opacity，不阻塞交互 |
| 不适品类暗黑模式 | 政务、医疗、金融场景使用深色底 | 该场景固定浅色底 |
| 低对比度正文 | 正文与底色对比度低于 4.5:1 | 调整文字色或加深底色，按 `references/ui-design-system-guide.md` 第 3.2 节复算 |
