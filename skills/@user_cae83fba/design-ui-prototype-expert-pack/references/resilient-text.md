# 05 段弹性文本规则

本文件是弹性文本规则的**唯一权威定义**。`experts/05-ui-to-prototype-expert.md` 与 `workflows/frontend-handoff.md` 引用本文件，不另立清单。

核心目标：文本在窄屏、字号放大、动效降级三种情况下仍完整可读。

## 1. 八条规则

| 编号 | 规则 | 禁止做法 | 正确做法 |
|---|---|---|---|
| T1 | 标题换行是渐进增强 | 靠 `<br>` 才能正常显示的标题 | 自然换行在任意宽度下均可用，手动换行标记只作增强 |
| T2 | 必要文本不可截断 | 固定高度加 `overflow: hidden`；对价格、日期、状态用 `text-overflow: ellipsis` | 用 `min-height` 让容器随内容增长 |
| T3 | Chip 与 Tag 溢出处理 | 标签平铺溢出容器 | 用 `flex-wrap: wrap` 换行，或显示前 N 个其余用 `+3` 披露 |
| T4 | Badge 不能只靠颜色传达意义 | 仅用红点表示失败 | 颜色、图标、文字三者至少提供两个 |
| T5 | 实时计数需语境 | 只显示 `12` | 显示「12 条未读」或补 `aria-label` |
| T6 | 快速交互可取消动画，但终态必须正确 | 跳过动画后 `aria-expanded` 仍为旧值、焦点丢失 | 压缩动效时长但不移除状态变更逻辑 |
| T7 | 窄屏按钮换行与触控尺寸 | 按钮文字换行后低于 44x44 | 允许换行并保证换行后仍 >= 44x44，或改用整行按钮 |
| T8 | 表格与数字的退化行为 | 关键列横向滚动后不可见；数字与单位被拆行 | 冻结关键列；数字与单位用 `white-space: nowrap` 保持一体 |

**关于条数**：本清单为 8 条。早期版本在不同文件中分别记为 5 条或 6 条，属历史不一致，已统一。判断某段是否达标时，一律以本表 8 条为准。

## 2. 规则补充说明

### T1 标题换行

去掉全部手动换行标记后，标题在任意宽度下都不能破版。中文长标题额外注意：单个长词（如产品名、英文技术名）在窄屏需允许断行或内部换行，不能靠溢出隐藏。

### T2 必要文本不可截断

价格、日期、状态、金额、编号属于必要信息，截断后无法完成判断。表格列宽不足时的正确做法是换列、卡片化或允许换行，不使用省略号。

### T3 Chip 与 Tag 溢出

紧凑标签尽量显示完整，「进行中」比「进…」有用。必须折叠披露时，披露入口需可点击并带 `aria-expanded`。

### T4 Badge 状态冗余

约 8% 男性存在红绿色觉分辨困难。失败、成功、待处理三类状态至少提供两种区分通道。示例：红色加叉号图标加屏读文本「失败」。

### T5 实时计数语境

裸数字在界面中无含义。计数元素需给出单位与对象，或补 `aria-label="12 条未读消息"`。

### T6 动效降级

降级只压缩动效时长，不移除状态变更逻辑。实现方式：

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}
```

快速连点场景同样适用：动画可跳过，`aria-expanded`、`aria-selected` 与焦点位置必须先于动画完成更新。

## 3. 交付前 3 步实测法

| 步骤 | 操作 | 判定标准 |
|---|---|---|
| 1 | 视口缩至 320px 宽 | 无截断、无横向溢出、必要文本完整 |
| 2 | 浏览器字号调至 200% | 布局不破，主操作仍可见可点 |
| 3 | 开启 `prefers-reduced-motion` | 状态正确（`aria-*` 属性为终态值）、焦点未丢 |

任一步不通过即视为不通过，回到修正后重测。三步都要在真实浏览器执行，看代码不算验证。

## 4. 常见问题定位

| 现象 | 根因 | 处理 |
|---|---|---|
| 窄屏标题只剩一个字 | 手写 `<br>` 覆盖了自然换行 | 移除手动换行标记，改约束最大宽度 |
| 价格显示为「199.」 | 对价格用了 `text-overflow` | 移除省略号，容器改 `min-height` |
| 标签横向撑出卡片 | Chip 容器未设 `flex-wrap: wrap` | 补换行规则或改折叠披露 |
| 深色模式下状态点看不出 | 只用颜色区分状态 | 补图标与文字通道 |
| 快速点击后折叠面板不动 | 状态更新写在动画回调里 | 状态先更新，动画只负责表现 |
