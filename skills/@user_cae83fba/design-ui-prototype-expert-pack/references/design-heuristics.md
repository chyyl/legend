# 启发式评分（可选交叉验证维度）

供 06 段评审在需要可用性评估时使用。评分标尺 0 至 4 分，4 分为真正优秀，不是「够用就行」。

## 0. 定位声明

| 项 | 说明 |
|---|---|
| 性质 | 可选交叉验证维度 |
| 触发条件 | 用户明确要求做可用性评估；或 06 段结论为「带风险通过」时由评审者提议 |
| 与 7 维 100 分制的关系 | 不替代、不参与结论判定、不合并不换算 |
| 呈现方式 | 与 100 分制评分并行呈现，各自独立成表 |
| 证据要求 | 无证据的条目标「未评」并说明原因 |

## 1. 通用评分标尺

10 条启发式的 0 至 4 分含义一致，按下表取分，再结合各条检查点判断处于哪一档。

| 分 | 通用含义 |
|---|---|
| 0 | 该维度完全缺失，用户只能靠猜 |
| 1 | 仅有零星覆盖，多数场景无效 |
| 2 | 部分覆盖，主路径可用，边缘场景缺失 |
| 3 | 覆盖良好，个别场景有缺口 |
| 4 | 覆盖完整且到位，可作为同类产品基准 |

## 2. 十条启发式：定义与检查点

| 编号 | 名称 | 定义 | 检查点 |
|---|---|---|---|
| H1 | 系统状态可见 | 通过及时且恰当的反馈让用户了解系统状态 | 异步操作有加载指示；保存、提交、删除后有确认；多步流程有进度；导航当前位置可见（面包屑、激活态）；表单校验为内联反馈 |
| H2 | 系统与用户世界匹配 | 使用用户语言，遵循真实世界惯例，信息按自然逻辑顺序出现 | 术语熟悉无未解释行话；信息顺序符合预期；图标与隐喻可识别；用语贴合目标受众；阅读流自然 |
| H3 | 用户控制与自由 | 用户可从非预期状态中清晰退出，不被迫进入冗长对话 | 有撤销与重做；表单与弹窗有取消；能清晰返回安全位置；可清除筛选、搜索与选择；可中途退出长流程 |
| H4 | 一致性与标准 | 同一词汇、情境与操作不引起歧义 | 术语全局一致；相同操作结果相同；遵循平台惯例；视觉一致（颜色、字体、间距、组件）；交互模式一致 |
| H5 | 错误预防 | 优先从设计上阻止问题发生，优于事后补救 | 破坏性操作前确认；控件限制非法输入；智能默认值降低出错；标签清晰；自动保存与草稿恢复 |
| H6 | 识别优于回忆 | 降低记忆负担，让对象、操作与选项可见或易取 | 选项可见（不藏于隐藏菜单）；需要时有上下文帮助；有最近项与历史；自动补全与建议；图标有文字标签 |
| H7 | 灵活性与效率 | 为熟练用户提供加速手段，同时不加重新手负担 | 常用操作有快捷键；界面可定制；有最近项与收藏；支持批量操作；高级功能不增加基础操作负担 |
| H8 | 美观与极简 | 界面不含无关或极少需要的信息，每个元素都有用途 | 每步只显示必要信息；视觉层级清晰；颜色与强调有明确用途；无装饰性干扰；布局聚焦不杂乱 |
| H9 | 错误识别、诊断与恢复 | 错误提示用平实语言，精确指出问题，并给出建设性建议 | 不用错误码；精确定位问题（如「邮箱缺少 @」而非「输入无效」）；给可执行建议；错误显示在问题源附近；非阻断式处理，不清空已填表单 |
| H10 | 帮助与文档 | 帮助易于查找、按任务组织、简洁 | 有可搜索的帮助；上下文帮助（提示、就地说明、引导）；按任务而非按功能组织；内容简洁可扫读；不离开当前上下文即可获取 |

## 3. 分档参照

各条得分按下表定位到总体评级。分档只描述整体水平，不参与 06 段结论判定。

| 分数区间 | 评级 | 含义 |
|---|---|---|
| 36 至 40 | 优秀 | 仅需打磨，可交付 |
| 28 至 35 | 良好 | 补齐薄弱处，基础扎实 |
| 20 至 27 | 可接受 | 需明显改善才达到用户满意 |
| 12 至 19 | 较差 | 需大幅改造，核心体验有断裂 |
| 0 至 11 | 严重 | 需重新设计，当前状态不可用 |

## 4. 问题严重度分级

| 级别 | 名称 | 描述 | 动作 |
|---|---|---|---|
| P0 | 阻断 | 完全无法完成任务 | 立即修复 |
| P1 | 严重 | 导致明显困难或困惑 | 发布前修复 |
| P2 | 轻微 | 造成不便但有绕过方式 | 下一轮修复 |
| P3 | 打磨 | 影响很小，无实际用户影响 | 有余量时修复 |

严重度标注与 06 段主结论的 P0 / P1 / P2 分级并行使用，不合并统计。

## 6. 使用纪律

| 编号 | 规则 |
|---|---|
| N1 | 评分须有证据，证据为空则该条标「未评」并说明原因 |
| N2 | 未实际读取页面或原型时不评分，只列待核对项 |
| N3 | 启发式分数不参与 06 段通过与带风险通过的判定 |
| N4 | 分数不与 100 分制评分换算，不做加权合并 |
| N5 | 结论为「带风险通过」时，启发式结果作为附录呈现 |
