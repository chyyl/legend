# 交付前检查表

交付前逐项过一遍。任何一项不通过，不交付。前 8 项为通用项，后 2 项为本技能包特有项。

## 1. 十项检查

| 编号 | 检查项 | 通过标准 | 勾选格式 | 高危说明 |
|---|---|---|---|---|
| C1 | 无 emoji 当图标 | 界面图标为统一图标集 SVG，无 emoji 字符 | `[ ] C1 图标：无 emoji / 混用风格 □` | 高危：emoji 跨平台渲染差异大，尺寸与颜色不可控 |
| C2 | 对比度达标且可复算 | 正文 >= 4.5:1；大字号（>= 24px 或 >= 18.66px 粗体）与图标、控件 >= 3:1；输出含计算过程 | `[ ] C2 对比度：正文 __:1 / 控件 __:1（计算记录见附表）` | 高危：CTA 按钮与灰色辅助文字最常不达标 |
| C3 | 焦点态可见 | 未移除默认 outline，或已提供等效替代样式，焦点环对比度 >= 3:1 | `[ ] C3 焦点态：□ 未移除默认态 □ 已提供替代样式` | 高危：移除 outline 且无替代，键盘用户完全无法定位 |
| C4 | 响应式断点齐全 | 覆盖 375、768、1280 三档，且 1920 有内容区限宽规则 | `[ ] C4 断点：375 □ 768 □ 1280 □ 1920 □` | 缺 1920 时超宽屏内容拉伸，阅读行长超阈值 |
| C5 | 弹性文本 | 窄屏、放大字号、动效降级三种情况均不截断 | `[ ] C5 弹性文本：320px □ 200% □ reduced-motion □` | 高危：默认字号下看不出，用户放大后破版 |
| C6 | 动效可取消 | 支持 `prefers-reduced-motion`；动画可中断；终态与焦点状态正确 | `[ ] C6 动效降级：□ 终态正确 □ 焦点未丢` | 只去掉动画而状态未更新，比不做动效更糟 |
| C7 | 语义化与无障碍属性 | 使用正确标签；图标按钮补 `aria-label`；表单控件关联 `label`；状态变更用 `aria-expanded` / `aria-live` | `[ ] C7 语义：button/nav/main □ aria-label □ label □` | 用 `div` 模拟按钮会丢失键盘与读屏支持 |
| C8 | 命名与 token 一致 | 颜色、字号、间距使用 token 名；无同义不同名（如主色与品牌蓝并存） | `[ ] C8 命名：□ token 一致 □ 无同义不同名` | 命名分叉导致设计系统无法收敛 |
| C9 | 行业反模式对照 | UI 规格 AVOID 栏逐条确认未踩，含 Neumorphism 与 Glassmorphism 未用于正文承载 | `[ ] C9 行业反模式：已对照 __ 项 AVOID □` | 金融、政务场景误用玻璃拟态会削弱可信度 |
| C10 | 需求覆盖矩阵完整 | 每一项需求都能对应到产物中的具体章节，无遗漏无孤立需求 | `[ ] C10 覆盖矩阵：__ 项需求全部有对应章节 □` | 遗漏项在评审阶段才会暴露，返工成本最高 |

## 2. 自检执行顺序

```
1. 先跑 C1 至 C10 逐项检查
2. 再对照 UI 规格的 AVOID 栏逐条确认
3. 最后在真实浏览器或设备上点一遍（看代码不算验证）
```

第 3 步的真实走查才是证据。

## 3. 高危项说明

| 项 | 为什么常被跳过 | 代价 |
|---|---|---|
| C2 对比度 | 设计稿上看着清楚 | 弱视用户完全读不到 |
| C3 焦点态 | 鼠标点击看不出差异 | 键盘用户无法使用 |
| C5 弹性文本 | 默认字号下无问题 | 用户放大到 200% 时布局破版 |
| C9 行业反模式 | 用户说「好看就行」 | 与品类气质冲突，转化率下降 |
| C10 需求覆盖 | 只检查页面完整性 | 评审时被质疑需求理解偏差 |

## 4. 单项证据要求

| 项 | 证据形式 |
|---|---|
| C2 | 列出前景色、背景色、计算式与结果比值 |
| C3 | 列出焦点态样式定义位置 |
| C4 | 列出各断点下的布局变化表 |
| C5 | 记录三种实测场景的结果 |
| C7 | 列出关键元素的标签与属性 |
| C10 | 附需求覆盖矩阵表 |

第 2、5、10 项必须给可复算或可查表证据，其余项勾选加简要说明即可。

## 5. 与阶段的关系

| 项 | 主要执行阶段 |
|---|---|
| C1、C2、C8 | 04 段 UI 规格与设计系统 |
| C4、C5、C6 | 05 段原型与前端交接 |
| C3、C7 | 05 段与 06 段评审 |
| C9 | 03 段与 04 段（AVOID 栏来源） |
| C10 | 06 段评审 |

## 6. 复审触发条件

| 触发 | 动作 |
|---|---|
| 结论为「带风险通过」 | 重跑 C2、C5、C7 三项 |
| 新增页面或新增组件 | 重跑 C4、C5、C7 |
| 引入外部品牌 token | 重跑 C2，见 `references/brand-token-index.md` |
| 结论为「不通过」 | 记录不通过项与修正动作，回到产出阶段 |
