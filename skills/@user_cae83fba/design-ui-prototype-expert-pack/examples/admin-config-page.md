# 示例：后台配置页

本示例演示配置类后台页面的完整交付结构。重点是配置项的生命周期状态，以及回滚机制与权限边界的明确表达。

## 输入

| 项 | 内容 |
|---|---|
| 原始输入 | 运营团队需要配置业务规则、预览影响范围，并在确认后发布变更。 |
| 目标用户 | 运营人员负责日常规则调整；运营主管负责发布与回滚；只读用户仅查看当前生效版本。 |
| 业务目标 | 让规则变更可预览影响范围后再发布，降低配错导致的服务异常。 |
| 非目标 | 不做代码级配置下发；不做多环境差异对比；不做历史版本的自动回滚策略配置。 |
| 使用端 | 桌面端管理后台，最小可用宽度 1024px。 |
| 交付物类型 | 页面清单、线框规格、UI 规格、状态机、交接清单、评审报告。 |
| 输入缺口 | 审批是否必需、回滚是否保留历史版本、灰度发布是否在范围内，三项待确认。 |

## 产品结构

| 项 | 内容 |
|---|---|
| 目标 | 规则变更在发布前可预览影响范围，发布后可追溯到具体版本。 |
| 非目标 | 不做实时生效；不做跨环境配置同步；不提供配置项级别的权限颗粒度。 |
| 用户 | 运营人员、运营主管、只读用户三类角色，权限按角色区分。 |
| 主场景 | 运营人员调整一条规则，查看受影响的数据量，确认后由主管发布。 |
| 主路径 | 编辑规则 → 预览影响 → 校验规则 → 发布 → 记录版本。 |
| 分支路径 | 保存草稿、放弃修改、切换规则、回滚到历史版本、复制现有规则。 |
| 空状态 | 规则列表首次进入无任何配置，需引导创建第一条规则。 |
| 加载状态 | 预览计算与发布均需等待，等待期间锁定编辑区。 |
| 错误状态 | 校验失败、发布失败、预览计算失败三类需分别处理。 |
| 权限状态 | 无发布权限、无回滚权限、只读三类需分别拦截。 |
| 关键风险 | 回滚机制与权限边界未定，直接影响是否可进入评审。 |

## 页面清单

| 页面 | 页面目标 | 存在理由 | 入口 | 主要操作 | 覆盖状态 |
|---|---|---|---|---|---|
| 规则列表 | 让运营定位需要维护的规则 | 规则数量超过十条，需要检索与分类 | 左侧导航「业务规则」 | 打开编辑器 | 主态、空态、加载态、错态、权限态 |
| 规则编辑器 | 修改单条规则的取值与条件 | 配置动作的承载页面 | 规则列表行操作 | 保存草稿 | 主态、加载态、错态、权限态 |
| 影响预览 | 展示本次变更影响的数据范围 | 配置类页面的核心风险控制点 | 编辑器内触发 | 发起校验 | 主态、加载态、错态 |
| 发布确认 | 二次确认并展示影响摘要 | 高风险操作需在提交前再确认一次 | 预览通过后触发 | 发布变更 | 主态、加载态、错态、权限态 |
| 版本历史 | 支持追溯与回滚 | 配置变更需可审计 | 编辑器顶部入口 | 回滚到指定版本 | 主态、空态、加载态、错态、权限态 |

## 配置项生命周期状态

| 状态 | 含义 | 进入条件 | 可执行操作 | 退出条件 |
|---|---|---|---|---|
| 草稿 | 修改已保存但未发布 | 编辑器点击保存草稿 | 继续编辑、放弃修改 | 发起校验通过后进入校验中 |
| 校验中 | 正在检查取值合法性与影响范围 | 发起校验 | 等待，不可编辑 | 校验结束进入校验失败或进入发布确认 |
| 校验失败 | 存在不合规取值或影响面过大 | 校验发现阻断项 | 按提示修正后重新校验 | 修正后回到校验中 |
| 发布中 | 已提交发布请求，等待生效 | 发布确认通过 | 查看进度，不可编辑 | 发布完成进入已发布或回到校验失败 |
| 已发布 | 当前生效版本 | 发布成功 | 发起下一次编辑或回滚 | 下一次发布或回滚后重新记录版本 |
| 回滚中 | 正在恢复到指定历史版本 | 主管确认回滚 | 查看进度，不可编辑 | 回滚完成进入已发布或回滚失败 |

回滚机制写明三条：回滚只允许整版本恢复，不支持单个配置项恢复；回滚会生成一个新的版本记录，历史记录不覆盖；回滚需要主管权限，普通运营人员只能发起回滚申请。

## 五状态覆盖明细

### 规则列表

| 状态 | 文案 | 交互 |
|---|---|---|
| 空态 | 还没有配置任何业务规则。创建第一条规则后，可在发布前预览它影响的数据范围 | 主操作为「创建规则」，页面内不放其他可点击动作 |
| 加载态 | 正在获取规则列表 | 表格骨架行占位，行高与真实行一致 |
| 错态 | 规则列表加载失败，请检查网络后重试 | 表格区保留表头，主体区给重试按钮 |
| 权限态 | 你没有查看业务规则的权限，可联系运营主管申请 | 页面整体替换为权限说明，不渲染规则名称 |

### 规则编辑器

| 状态 | 文案 | 交互 |
|---|---|---|
| 空态 | 配置项均已填默认值，可直接修改后保存草稿 | 首屏不弹空态提示，直接呈现默认值与「默认值」标记 |
| 加载态 | 正在读取规则详情，读取期间编辑区禁用 | 骨架填充表单区，禁用提交与保存 |
| 错态 | 规则读取失败，返回列表后重试可恢复本次未保存的输入 | 编辑区保留输入内容，另给返回按钮 |
| 权限态 | 规则「当前已有待发布版本，你只能查看不能修改」 | 所有输入项转只读，保存草稿按钮隐藏 |

### 影响预览

| 状态 | 文案 | 交互 |
|---|---|---|
| 空态 | 尚未发起预览。修改取值后可预览受影响的数据范围 | 预览按钮为主操作，未修改时置为禁用 |
| 加载态 | 正在计算影响范围，数据量大时可能需要 10 秒 | 计算期间显示进度提示，编辑区锁定 |
| 错态 | 影响范围计算失败，本次预览不生效。请稍后重试 | 保留上次成功结果并标注结果时间 |
| 权限态 | 无需额外权限，沿用编辑器页权限 | 不展示 |

### 发布确认

| 状态 | 文案 | 交互 |
|---|---|---|
| 空态 | 校验未通过时不进入发布确认 | 不展示弹窗，焦点回到校验失败项 |
| 加载态 | 正在发布，本次变更将在 30 秒内生效 | 弹窗内锁定确认按钮并显示进度 |
| 错态 | 发布失败，本次变更未生效。配置仍停留在草稿状态 | 弹窗保留，错误下方给「返回草稿」与「重试发布」 |
| 权限态 | 你没有发布权限，可保存草稿后提交给运营主管发布 | 确认按钮禁用并说明原因，不隐藏入口以免用户无从判断进度 |

### 版本历史

| 状态 | 文案 | 交互 |
|---|---|---|
| 空态 | 该规则还没有发布记录。完成一次发布后，这里会记录每次变更 | 时间线区给说明文字，不给操作按钮 |
| 加载态 | 正在获取版本记录 | 时间线骨架占位 |
| 错态 | 版本记录加载失败，回滚操作在加载完成前不可用 | 回滚按钮禁用并说明原因 |
| 权限态 | 你没有回滚权限，可提交回滚申请由运营主管处理 | 回滚按钮禁用，另给「申请回滚」入口 |

## 响应式三档

| 断点 | 布局 | 主操作位置 |
|---|---|---|
| 至 767px，单列折叠 | 编辑器与预览上下排列，预览区改为抽屉打开，抽屉从右侧滑入 | 保存草稿置于底部固定条，发布置于预览抽屉内 |
| 768 至 1279px，双列 | 编辑器在上、预览在下，两者在滚动方向上对齐，视口高度足够时并排 | 发布按钮置于编辑器右上 |
| 1280px 及以上，双栏并排 | 左侧编辑右侧预览，两栏独立滚动，发布按钮固定在右上 | 页面右上，紧邻版本历史入口 |

配置类页面在 1280px 以下不承诺完整可用，最小可用宽度为 1024px，低于该宽度时提示使用更大视口。

## 交互反馈时序

| 交互对象 | 触发 | 即时反馈 | 成功反馈 | 失败反馈 | 期望时序 |
|---|---|---|---|---|---|
| 保存草稿 | 点击 | 按钮进入加载态并禁用 | 顶部提示草稿已保存，版本号更新 | 保存失败时保留输入内容并给重试 | 150 至 300ms 内出现加载反馈 |
| 发起校验 | 点击 | 预览区切换为计算中，编辑区锁定 | 展示影响范围摘要，发布按钮变为可用 | 计算失败时保留上次成功结果并标注时间 | 立即切换为计算中，10 秒内给结果或超时提示 |
| 发布变更 | 确认弹窗点击 | 弹窗内锁定按钮并显示进度 | 弹窗关闭，版本历史新增记录 | 发布失败时弹窗保留并给返回草稿与重试 | 150 至 300ms 内出现加载反馈 |
| 回滚版本 | 确认弹窗点击 | 弹窗内锁定按钮并显示目标版本号 | 回滚完成提示新的版本号与时间戳 | 回滚失败时保持当前生效版本不变 | 150 至 300ms 内出现加载反馈 |
| 切换规则 | 点击列表行 | 出现未保存变更确认 | 切换成功并载入新规则 | 有未保存修改时给保存、放弃、取消三项选择 | 150ms 内给出反馈 |

## 无障碍验收

| 检查项 | 规则 | 证据 | 结论 |
|---|---|---|---|
| 正文对比度 | 不低于 4.5:1 | 表单标签与输入值比值记录在 UI 规格 contrastChecks | 待实现后复测 |
| 关键控件对比度 | 发布与回滚按钮边界不低于 3:1 | 两个按钮的描边与填充色分别记录比值 | 待实现后复测 |
| 风险操作三重提示 | 颜色、图标、文字三者至少两个 | 发布按钮为错误色加发布图标加「发布」文字 | 设计已满足 |
| 字段级错误定位 | 校验错误落在对应字段下方 | 校验失败清单逐条给出字段名与规则 | 设计已满足 |
| 键盘可达 | 表单与弹窗可全键盘操作，焦点不丢 | 弹窗打开时焦点移入，关闭后回到触发按钮 | 待实现后复测 |
| 焦点可见 | 键盘聚焦时有可见轮廓 | 焦点态写入组件状态表 focus 项 | 待实现后复测 |
| 状态冗余表达 | 生命周期状态不能只靠颜色 | 状态标签为色块加文字，发布中额外带进度指示 | 设计已满足 |
| 动效降级 | 降级只压缩时长，不移除状态变更逻辑 | 抽屉滑入动效在降级偏好下时长压到 0.01ms，焦点与 aria 状态仍更新 | 待实现后复测 |

## 待确认问题

| 编号 | 问题 | 选项 | 影响 |
|---|---|---|---|
| Q1 | 发布是否需要审批 | 不需要主管确认，运营可直接发布 / 需要主管审批后发布 / 视规则风险级别区分 | 决定发布确认弹窗是单次确认还是提交加审批两段式 |
| Q2 | 回滚的权限范围 | 仅运营主管可执行 / 运营与主管均可 / 所有人可执行，需二次确认 | 决定版本历史页的权限态与确认层级 |
| Q3 | 影响面超过多大时必须阻断 | 影响超过 30% 阻断 / 超过 50% 阻断 / 不阻断只提示 | 决定校验失败的判定阈值与预览区文案 |
| Q4 | 是否保留历史版本用于回滚 | 保留最近 10 个版本 / 保留全部 / 保留 90 天内版本 | 决定版本历史页的时间线范围与存储说明 |
| Q5 | 是否需要灰度发布 | 需要按流量比例发布 / 只支持全量发布 | 决定发布确认弹窗是否需要增加比例输入项 |

Q1、Q2、Q3 阻断进入开发。Q4 与 Q5 可先按选项 A 推进并标注为假设。
