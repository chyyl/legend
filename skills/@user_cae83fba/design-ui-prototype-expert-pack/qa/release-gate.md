# 发布门禁

本文件定义技能包发布前的硬门禁。命中任一条即暂缓发布，不接受带风险放行。问题分级见 `qa/delivery-checklist.md`，评分操作见 `qa/scoring-workflow.md`。

## 执行方式

1. 按 `tests/regression-cases.yaml` 的 12 条用例逐条执行。
2. 每条校验四项：预期路由是否命中、最低输出是否覆盖、结论是否证据化、信息不足时是否正确降级。
3. 执行记录填入 `tests/result-template.md`。
4. 12 条全部执行完毕后再判定发布结论，不允许抽样跳过。

## 12 条硬门禁

| 编号 | 门禁项 | 判定标准 | 命中后果 |
|---|---|---|---|
| G1 | 路由正确性 | 12 条用例的 expectedRoute 全部命中 | 暂缓发布 |
| G2 | 输出契约稳定性 | requiredOutputs 全部覆盖，无缺字段 | 暂缓发布 |
| G3 | 证据可复核 | 每条结论可定位到文件与行号或区块名 | 暂缓发布 |
| G4 | 降级正确性 | 信息不足时全部走降级出口，无强行主交付 | 暂缓发布 |
| G5 | 品牌中立 | 全文无第三方品牌词，大小写与连字符变体均为零命中 | 暂缓发布 |
| G6 | 信息脱敏 | 全文无本机绝对路径、用户名、真实客户名 | 暂缓发布 |
| G7 | 状态覆盖 | 每页含主态、空态、错态、加载态、权限态 | 暂缓发布 |
| G8 | 无障碍门槛 | 普通文本对比度不低于 4.5:1，关键控件不低于 3:1 | 暂缓发布 |
| G9 | 非生产边界 | 评审级原型均声明 scopeBoundary，isProductionCode 为 false | 暂缓发布 |
| G10 | Schema 一致性 | 专家文件字段名与 data/schemas 属性名一致，JSON 可解析 | 暂缓发布 |
| G11 | 评分可复评 | 七维评分每维有 deductions，总分与档位匹配 | 暂缓发布 |
| G12 | 包结构完整 | SKILL.md 可解析，无隐藏文件与嵌套压缩包 | 暂缓发布 |

| 用例 | 预期路由 | 必须输出 | 通过条件 |

| R2 | 01 到 02 | 页面目标、区块、主次操作、跳转、状态 | 每页有目标，关键状态齐备 |

## 发布判定

### 通过发布

需同时满足：

- 12 条用例全部通过。
- 12 条硬门禁无一命中。
- R5 质量评分不低于 90，且无关键证据缺失。
- G5 与 G6 扫描零命中。

### 带风险发布

需同时满足：

- 至少 11 条用例通过。
- 硬门禁 G5、G6、G10、G12 全部通过。
- 已列出明确修复计划与责任人。
- 修复计划含回归复测范围。

### 暂缓发布

任一情况：

- 通过用例少于 11 条。
- G5、G6、G10、G12 任一命中。
- 出现 P0 阻断项。
- QA 结论或评分不可复核。

## 建议归档材料

- 回归执行记录表，含每条用例的输出摘要。
- 失败用例修复说明。
- 门禁扫描原始输出，含扫描命令与命中数。
- 最终发布结论与负责人确认。
